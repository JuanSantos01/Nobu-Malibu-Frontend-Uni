Fundamentación Matemática del Modelo

Este módulo resuelve un Problema de Asignación de Recursos con Restricciones Lineales. El algoritmo procesa los datos de entrada para encontrar el punto de equilibrio operativo óptimo.

Formulación Estándar (IO):
• Función Objetivo: Minimizar Z = Costo_Mesa × Mesas_Abiertas
• Restricción 1 (Demanda): (Mesas_Abiertas × Capacidad_Mesa) ≥ Invitados
• Restricción 2 (Física): Mesas_Abiertas ≤ Total_Mesas_Disponibles

Ejemplo Práctico de Procesamiento:

Si configuras 5 invitados y un inventario de 7 mesas: El modelo calcula mediante la función techo que requieres matemáticamente 2 mesas para mantener el confort (4 personas por mesa). Como 2 ≤ 7, el sistema aprueba abrir únicamente 2 mesas, minimizando el costo operativo total a solo 2 unidades de tasa de limpieza.
